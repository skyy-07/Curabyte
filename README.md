# Curabyte

Curabyte is a smart food management and meal planning application designed to help users minimize food waste, plan healthy meals, and streamline their grocery shopping. Built with React and powered by Google's Gemini AI, it offers features like fridge scanning, voice entry, and intelligent recipe generation.


## 🌐 Live Demo

Try out the beta version of the app here: [Curabyte Beta](https://melodious-biscotti-2e4d8b.netlify.app/)

## 🚀 Features

- **Inventory Management**: Keep track of your pantry and fridge items, including expiry estimates.
- **Smart Recipe Generation**: AI-powered meal planning based on your available ingredients and health profile.
- **Fridge Scanner**: Use your camera to automatically detect and add ingredients to your inventory.
- **Voice Entry**: Quickly add items to your inventory or shopping list using voice commands.
- **Grocery List**: Integrated shopping list that auto-populates from meal plans.
- **Health Tracking**: Integrates with user stats (steps, calories burned) to customize meal recommendations.
- **Cloud Sync**: Syncs your data across devices (simulated/implemented via storage service).

## 🛠️ Tech Stack

- **Frontend Framework**: React (Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **AI Integration**: Google GenAI (Gemini)
- **Icons**: Lucide React
- **Charts**: Recharts
- **Camera**: React Webcam

## ⚡ Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1.  Clone the repository:
    ```bash
    git clone <repository-url>
    cd curabyte
    ```

2.  Install dependencies:
    ```bash
    npm install
    # or
    yarn install
    ```

3.  Set up Environment Variables:
    Create a `.env.local` file in the root directory and add your API keys (e.g., Google Gemini API key) if required by the *services*.

4.  Run the Development Server:
    ```bash
    npm run dev
    ```

5.  Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

## 📜 Scripts

- `npm run dev`: Starts the development server.
- `npm run build`: Builds the app for production.
- `npm run preview`: Previews the production build locally.
